# 8 bit CPU

## Specifications

- Von - Neumann architecture
- Data bus - 8 bits
- Address bus - 8 bits
- Instruction width - 16 bits
- Data memory - 1024 B
- Instruction memory - 256 words
- Sequential, multi cycle

## Instruction Set

- 0001: mov
- 0010: load
- 0011: store
- 0100: add
- 0101: subtract
- 0110: xor    
- 0111: multiply
